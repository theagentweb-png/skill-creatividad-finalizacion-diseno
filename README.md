# Skills de agencia

La biblioteca está organizada en [agencia](agencia/README.md), por los seis roles del equipo: Coordinador, Community manager, Creativo, Media Buyer, Web Shopify y Asesor comercial.

Incluye las especializaciones profesionales existentes, con sus referencias y recursos. Los briefs y aprendizajes de cada cliente se administran por separado en el dashboard.

La skill de finalización original permanece en la raíz por compatibilidad. Para navegar y mantener el equipo, empieza por [el índice de agencia](agencia/README.md).
